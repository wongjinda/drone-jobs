# รับงานโดรนเกษตร

เว็บแอปจองงาน คิวงาน ลูกค้า/แปลงนา และสรุปรายได้ สำหรับงานโดรนเกษตร

- เปิดใช้งาน: https://wongjinda.github.io/drone-jobs/
- ข้อมูลเก็บใน Supabase (โปรเจกต์ `drone-jobs`) ล็อกอินด้วยอีเมล แต่ละบัญชีเห็นเฉพาะข้อมูลของตัวเอง (Row Level Security)
- คีย์ใน `index.html` เป็นคีย์สาธารณะ (anon) ที่ออกแบบมาให้ใช้ในเว็บ ไม่ใช่รหัสลับ

## สมุดบัญชีชาวนา (`/ledger/`)

- เปิดใช้งาน: https://wongjinda.github.io/drone-jobs/ledger/
- บัญชีรายรับรายจ่าย ทำนา · รับจ้างเกี่ยวข้าว · รับจ้างโดรน + คำนวณภาษีเงินได้บุคคลธรรมดา + รอบการปลูก + รูปใบเสร็จ
- ล็อกอินด้วยบัญชีเดียวกับแอปรับงานโดรน ข้อมูลอยู่ในตาราง `ledger_records`, `ledger_settings` และรูปใบเสร็จใน Storage bucket `receipts` (ส่วนตัว แยกโฟลเดอร์ตาม user id) — ทุกตารางเปิด Row Level Security
- งานที่ปิดแล้วในตาราง `jobs` จะลงเป็นรายรับโดรนให้อัตโนมัติเมื่อเปิดแอปบัญชี
