# รับงานโดรนเกษตร

เว็บแอปจองงาน คิวงาน ลูกค้า/แปลงนา และสรุปรายได้ สำหรับงานโดรนเกษตร

- เปิดใช้งาน: https://wongjinda.github.io/drone-jobs/
- ข้อมูลเก็บใน Supabase (โปรเจกต์ `drone-jobs`) ล็อกอินด้วยอีเมล แต่ละบัญชีเห็นเฉพาะข้อมูลของตัวเอง (Row Level Security)
- คีย์ใน `index.html` เป็นคีย์สาธารณะ (anon) ที่ออกแบบมาให้ใช้ในเว็บ ไม่ใช่รหัสลับ
