# สมุดบัญชีชาวนา — ประวัติการพัฒนา

แต่ละเวอร์ชันมี git tag `ledger-v<เวอร์ชัน>` ใน repo นี้
เลขเวอร์ชันแบบ หลัก.รอง.แก้ไข: เลขหลักเปลี่ยนเมื่อหน้าตาหรือโครงสร้างเปลี่ยนมาก
เลขรองเปลี่ยนเมื่อเพิ่มความสามารถใหม่ เลขแก้ไขเปลี่ยนเมื่อแก้ปัญหาหรือปรับเล็กน้อย
เวลาออกเวอร์ชันใหม่ ให้เพิ่มรายการบนสุดของ `CHANGELOG` ใน `index.html` ด้วย แอปใช้รายการนั้นแสดงเลขเวอร์ชัน
